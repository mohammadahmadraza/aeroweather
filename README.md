# aeroweather
Note : Make sure you have install Node.js, and API keys of https://openweathermap.org/ and https://www.goflightlabs.com/ before following the below steps.

Go to https://github.com/mohammadahmadraza/aeroweather and click on Code button and click on Download ZIP option from the dropdown.
Extract the files, go to client folder and open the folder in command prompt.
Run the npm i command in the command prompt. and follow the same instructions by moving to server folder.
Now open your browser and enter the http://localhost:5173/ in search bar and hit enter button. Application frontend will be run in the browser.
